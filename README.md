# NIMEX Check-in Daily Dashboard

ระบบ Check-in รายวันของพนักงานขับรถ (ตรงเวลา / มาสาย / ไม่ตรงจุด / ไม่ Check in / ค่าปรับ) หน้าตาตาม NIMEX Design Kit

- repo นี้ไม่มีข้อมูลจริง ผู้ใช้อัปโหลดไฟล์ Excel ที่เมนู "อัปโหลดไฟล์ข้อมูล" ข้อมูลสะสมเก็บในเบราว์เซอร์ของเครื่องนั้น
- การคำนวณ เกณฑ์ค่าปรับ และการอ่านไฟล์เหมือนเดิมทุกอย่าง (ปรับเฉพาะหน้าตา)
- repo เป็นสาธารณะ ห้ามนำไฟล์ข้อมูลจริงขึ้น repo
