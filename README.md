# NIMEX Check-in Daily Dashboard

ระบบ Check-in รายวันของพนักงานขับรถ (ตรงเวลา / มาสาย / ไม่ตรงจุด / ไม่ Check in / ค่าปรับ) หน้าตาตาม NIMEX Design Kit
**repo นี้ไม่มีข้อมูลจริง** ห้ามนำไฟล์ Excel หรือไฟล์ข้อมูลขึ้น repo (repo เป็นสาธารณะ)

## ไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| index.html | หน้าแดชบอร์ดเดิม (การคำนวณ เกณฑ์ค่าปรับ การอ่านไฟล์ เหมือนเดิมทุกอย่าง) |
| config.js | ที่อยู่ Apps Script (`CID_API`) และเลขเวอร์ชัน (`CID_V`) |
| boot.js | โหลดผลและค่าตั้งจาก Google Sheet, แยกผู้ชม/ผู้ดูแล, ปุ่ม "💾 บันทึกลง Google Sheet", ย้ายข้อมูลเดิมจากเบราว์เซอร์ |
| share.js | ปุ่ม "📤 แชร์/ส่งออก" (Excel, PowerPoint, PNG ยาว, ข้อความ LINE) + อินโฟกราฟิก 16:9 และส่วนตั้งค่าเกรด/กราฟ |
| Code.gs.txt | โค้ดฝั่ง Apps Script (แท็บ Rows / Settings / Log) |

## โหมดการทำงาน
- `CID_API = ''` (ค่าเริ่มต้น): ทำงานแบบเดิม เก็บข้อมูลในเบราว์เซอร์เครื่องนั้น
- ใส่ URL `/exec`: ทุกเครื่องเห็นข้อมูลชุดเดียวกันจาก Google Sheet ผู้ชมดูได้อย่างเดียว

## ติดตั้ง Google Sheet ครั้งแรก
1. สร้าง Google Sheet ใหม่ → Extensions > Apps Script → วางเนื้อหา `Code.gs.txt` บันทึกเป็น Code.gs
2. Project Settings > Script Properties → เพิ่ม `ADMIN_KEY` = รหัสผู้ดูแล (ห้ามเขียนรหัสลงไฟล์ใดๆ ใน repo)
3. Deploy > New deployment > Web app > Execute as: **Me**, Who has access: **Anyone** → คัดลอก URL ที่ลงท้าย `/exec`
4. แก้ `config.js` ใส่ URL ที่ `CID_API` และเพิ่มเลข `CID_V`
5. เปิดเว็บบน **เครื่องที่เคยอัปโหลดข้อมูลไว้** ต่อท้าย `#admin` → ใส่รหัส → กด "⬆️ ย้ายข้อมูลเดิมขึ้น Google Sheet"
   (ถ้าไม่มีข้อมูลเดิม ให้ไปเมนูอัปโหลดไฟล์ แล้วกด "💾 บันทึกลง Google Sheet")

## ใช้งาน (ผู้ดูแล)
- กด "🔒 ระบบ" หรือเปิดลิงก์ต่อท้าย `#admin` → ใส่รหัส (ตรวจที่ Apps Script เท่านั้น)
- อัปโหลด / ประมวลผลใหม่ / Waive / แก้ Config เหมือนเดิม แล้วกด **"💾 บันทึกลง Google Sheet"** ที่แถบด้านบน ผู้ชมจึงเห็น
- การบันทึกเขียนลงแท็บชั่วคราวก่อน ถ้าส่งไม่ครบ ข้อมูลเดิมใน Sheet ยังอยู่ครบ
- ⚙️ ตั้งค่า → Config ค่าปรับราย DC: ติ๊ก **ยกเว้นทุกเงื่อนไข** หน้า DC = DC นั้นไม่ถูกนับและไม่แสดงผลทุกหน้า/ทุกไฟล์ส่งออก (ข้อมูลยังเก็บไว้ ติ๊กออกแล้วกลับมา) แล้วกด 💾 บันทึกลง Google Sheet
- แก้ Code.gs แล้วต้อง Deploy ใหม่: Manage deployments → ✏️ → เวอร์ชันใหม่ (ลิงก์ /exec เดิม)

## แชร์ / อินโฟกราฟิก
- ใช้ตัวกรองเดือน/วันที่บนหน้า "เสนอผู้บริหาร" (ไม่รวมวันอาทิตย์)
- KPI 6 ตัว: จำนวนรายการ, % ตรงเวลา, % สาย, % ไม่ Check in, % ไม่ตรงจุด, ค่าปรับรวม (1 รายการ = รถ 1 คันใน 1 วัน)
- ช่วงก่อนหน้า = จำนวนวันทำการ (จ.–ส.) เท่ากัน ติดกันก่อนวันแรกของช่วงที่เลือก
- เกรด DC จาก % ตรงเวลา **ปิดไว้ก่อน** ตั้งเกณฑ์และเปิดได้ที่ ⚙️ ตั้งค่า → "อินโฟกราฟิก / เกรด DC" พร้อมเลือกกราฟ 4 ช่อง (มี 7 แบบ)

## ความเป็นส่วนตัว
repo เป็นสาธารณะ และ Apps Script เปิดให้ทุกคนที่มีลิงก์อ่านได้ ใครมีลิงก์เว็บก็เห็นข้อมูลบนแดชบอร์ด (รวมทะเบียนรถ)
