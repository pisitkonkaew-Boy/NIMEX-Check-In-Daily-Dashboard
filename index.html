📊 ส่งข้อมูลไป Google Sheets

สร้าง Google Apps Script Web App แล้ว paste URL ด้านล่าง ระบบจะ POST ข้อมูลรายงานไปเก็บใน Google Sheets → เปิด Apps Script

📋 Apps Script Code.gs template:
function doPost(e){ var d=JSON.parse(e.postData.contents); var ss=SpreadsheetApp.getActiveSpreadsheet(); var sh=ss.getSheetByName("NIMEX_Report")||ss.insertSheet("NIMEX_Report"); if(sh.getLastRow()===0)sh.appendRow(["Timestamp","DateFrom","DateTo","Days","Total","OnTime","Late","WrongPlace","Absent","FineLate","FineWP","FineAbsent","TotalFine"]); sh.appendRow([new Date(),d.dateFrom,d.dateTo,d.days,d.totalRecords,d.onTime,d.late,d.wrongPlace,d.absent,d.lateFine,d.wpFine,d.abFine,d.totalFine]); return ContentService.createTextOutput("OK"); }
